Overview

This is a demonstration entry for the World Wiki. It shows the various formatting options available when writing entries. Each entry is a standalone HTML file — fully readable by search engines and crawlers without any JavaScript.

Details

Entries are stored in the entries/ folder. To create a new one, copy _template.html, rename it with a URL-friendly slug like my-new-topic.html, and fill in the content.

Don't forget to add a corresponding line to entry-index.json so it appears on the home page.
